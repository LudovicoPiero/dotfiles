# modules

~Home Manager~ modules, organized by category.

## Structure

- **apps** — user applications (firefox, music, games)
- **core** — foundational config and variables
- **desktop** — window managers and wayland/x11 tooling (hyprland, i3, niri, mango, noctalia shell, etc.)
- **dev** — development tools (git, gpg)
- **system** — system-level config (fcitx5, qemu, tlp, shared user/security setup)
- **terminal** — terminal emulators and shell (alacritty, ghostty, fish, tmux)
- **themes** — colors, fonts, gtk theming
